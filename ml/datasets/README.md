# Datasets

See [docs/ml/dataset.md](../../docs/ml/dataset.md) for the schema, sources, splits and limitations.

- `raw/synthetic/scamshield_synthetic_v1.csv` — hand-written development data (no real people's messages).
- `raw/external/` — downloaded public data (git-ignored): `npm run ml:fetch-data` fetches the UCI SMS
  Spam Collection v.1 (Almeida & Gómez Hidalgo, 2011; free use with attribution —
  http://www.dt.fee.unicamp.br/~tiago/smsspamcollection/).
- `processed/` — generated by `ml/training/preprocess.py` (git-ignored).
- `eval/scenario_suite.jsonl` — controlled held-out scenarios for `scripts/evaluate-system.ts`.

Schema: `text,label,category,source,language` (CSV or JSONL).
