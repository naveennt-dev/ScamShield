Features

A second pair of eyes for every message.

Scams depend on you acting fast. ScamShield slows the moment down and shows you what is wrong.

✉︎

Messages and screenshots

Scan the screen or a region on macOS — text is read on the Mac and the screenshot is discarded. On Android, paste a message or use Share → Check with ScamShield.

⌁

Links, without opening them

Spots look-alike brands (amaz0n), official names in front of another site (paypal.com-account-verify.xyz), punycode tricks, shorteners and risky endings.

?

Explains why

Every warning lists the signs it found — an OTP request, a threat, a fake bank link — and what to do next, including where to report it.

⌂

Private by design

Checks run locally. The Android app has no internet permission at all. History on the Mac stays on the Mac, with numbers masked.

!

Honest when unsure

If part of a check fails you see Unable to assess — never a false “safe”.

+

Optional AI second opinion

On macOS, off until you agree. It sees only masked text, uses your own key, and can raise a warning but never lower the on-device result.

How it works

Three independent checks, one clear answer.

  1. Safety rules — 59 rules across 18 scam families plus 5 combination rules: OTP and PIN requests, KYC threats, refund and prize bait, job and investment offers, remote-access requests. English, Hindi and Hinglish.
  2. Link analysis — every address in the message is checked for impersonation and deception.
  3. On-device ML model — estimates how scam-like the wording is (TF-IDF + logistic regression, trained on 3,771 messages).
  4. Risk fusion — combines them into a 0–100 score with safety guards: a clear rule or link finding can't be argued away, and the model alone can't raise a high-risk alarm.

Measured on test sets written for this project, not real-world traffic. No detector can guarantee a message is safe. Read the details →

Privacy

What you check stays with you.

  • No account, no sign-up.
  • Screenshots are read and discarded, never saved.
  • macOS History stays on your Mac and masks numbers, e-mail addresses and link paths.
  • The Android app cannot use the internet — Android itself enforces it.
  • The optional AI second opinion receives only masked text, after you agree.

Verify every download

Published files list a SHA-256 checksum. Compare it before opening: shasum -a 256 <file> (macOS, Linux) or Get-FileHash <file> (Windows). Download only from here or GitHub Releases.

FAQ

Questions

Does ScamShield read my messages automatically?

No. It only checks what you scan, paste or share with it.

Does it need the internet?

Not for the on-device checks. On macOS, only the opt-in “AI second opinion” mode uses the network. The Android app never does.

Is “No scam signs found” a guarantee?

No. It means none of the checks found a warning sign. When in doubt, contact the organisation using a number you already know.

Why is there no download yet?

The apps are in preview. The macOS app still needs Apple notarization and the Android app release signing and device testing. Releases will appear on GitHub with checksums.

How do I report a security problem?

Privately, through GitHub's vulnerability reporting — see the security policy. Never post real messages, OTPs or passwords in public issues.
